# Документация к игре

## О игре
Игра представляет собой текстовую RPG с элементами исследования мира, боёв и прокачки персонажа. 

Основные механики:
- Создание и загрузка персонажа
- Исследование случайно генерируемых локаций
- Сражения с врагами (гоблины, скелеты)
- Покупка и экипировка оружия/брони
- Система опыта и уровней
- Инвентарь с ограниченными слотами
- Система сохранения прогресса

Язык разработки: C++  
Рекомендуемый стандарт: C++17  
Поддерживаемые компиляторы:
- G++ 4.1+
- GCC 9.0+
- Clang 10+
- MSVC 2019+


## Системные требования
### Минимальные
1. Процессор: x86-64 архитектура
2. ОС: Windows 10 / Linux (последние LTS-версии)
3. 500 MB свободного места
4. Терминал с поддержкой UTF-8


## Сборка и запуск
### Требуемые зависимости
- CMake 3.15+
- Любой C++17-совместимый компилятор

### Инструкция по сборке: bash
# Клонировать репозиторий
git clone https://github.com/yourusername/game-project.git
cd game-project

# Создать build-директорию
mkdir build && cd build

# Сгенерировать проект
cmake ..

# Собрать проект
cmake --build .

# Запустить игру
./game_executable

## Команды
Классы, реализующие игровые действия через интерфейс "ICommand".

В данном классе существует функция виртуальный метод "CommandExecute()", которую переопределяют для использования в следующих классах:

### "EscapeCommand"
- CommandExecute()  
   Позволяет игроку сбежать из боя, возвращая его в город.

### "ExitCommand"
- CommandExecute()
   Завершает работу игры.

### "ExploreCommand"
- CommandExecute()
   Генерирует новую локацию, проверяет наличие врагов и переключает логику на бой или город.

### "FightCommand"
- CommandExecute()
   Инициирует бой: создает врагов и запускает цикл сражения.

### "LoadGameCommand"
- CommandExecute()
   Загружает сохранение по имени игрока и восстанавливает его прогресс (силу, уровень, защиту, предметы инвенторя).

### "NewGame"
- CommandExecute()
   Создает нового персонажа, сохраняет данные и начинает новую игру.

### "OpenShopCommand"
- CommandExecute()
   Открывает магазин, генерирует товары и переключает логику на магазин.

### "ShowInventoryCommand"
- CommandExecute()
   Отображает содержимое инвентаря игрока.

### "BuyCommand"
- CommandExecute()
   Позволяет игроку покупать предметы в магазине
   Запрашивает у пользователя номер предмета для покупки
   Обрабатывает ввод (игнорирует пробелы)
   Использует GetItemFromShop для получения предмета
   Применяет предмет через PlayerGetItem::Execute

### "CommandHandler"
- CommandExecute()
   Перенаправляет команду текущей игровой логике через LogicHandler
   Использует singleton-паттерн для доступа к единственному экземпляру
- GetInstance()
   Возвращает единственный экземпляр обработчика команд

### "ShowPlayerStats"
- CommandExecute()
   Отображает статистику игрока (здоровье, урон, уровень, опыт)
   Обрабатывает случай отсутствия игрока


## Персонажи
Классы, описывающие игровых сущностей.

### "Character" (Базовый класс)
- Attack(Character* target)
   Атакует цель, нанося урон.
- Take_Damage(float damage)
   Обрабатывает полученный урон.
- Heal(float heal)
   Восстанавливает здоровье.
- GetName()
   Возвращает имя персонажа
- GetInventory()
   Возвращает инвентарь персонажа
- GetHealth()
   Возвращает здоровье персонажа
- GetDamage()
   Возвращает урон персонажа

### "Player"
- AddExperience(float exp)
   Добавляет опыт, проверяет повышение уровня.
- GetExperience() const
   Возвращает имеющийся опыт.
- GetLevel() const
   Возвращает имеющийся уровень.
- LevelUp()
   Увеличивает уровень и остальные характеристики на константу.
- AddLevel()
   Проверяет и повышает уровень игрока, в зависимости от опыта(вызывает LevelUp()).
- EquipWeapon(std::shared_ptr<IItem> weapon)
   Экипирует оружие, увеличивая урон.
- EquipArmor(std::shared_ptr<IItem> armor)
   Экипирует броню, увеличивая защиту.
- AddItemToBackpack(std::shared_ptr<IItem> item)
   Добавляет предмет в инвентарь.
- RemoveItemFromBackpack(std::shared_ptr<IItem> item)
   Удаляет предмет из инвентаря.
- GetInventoryInfo() const
   Возвращает строку с информацией об инвентаре.
- SetHealth(float health)
   Обновляет информацию о здоровье.
- SetDamage(float damage)
   Обновляет информацию о уроне.
- SetInventory(IInventory* inventory)
   Обновляет инвентарь
- CreatePlayer(std::string name, float health, float damage)
   Создает нового игрока

### "Enemy"
- DropLoot()
   Генерирует и возвращает случайный предмет после смерти врага.
- GetGivenExp() const
   Возвращает количество опыта за убийство врага.
- GetDefence() const
   Возвращает количество брони врага.

### "EnemyFactory"
- CreateEnemy()
   Создает врагов.


## Предметы
Классы игровых предметов, реализующие интерфейс "IItem".

В данном классе существуют виртуальные медоты: GetInfo(), GetType(), GetTypeString(), которые переопределяют для использования в следующих классах:

### "Weapon" (Оружие)
- GetInfo()
   Возвращает информацию о уроне и слоте оружия.
- AddGem(Gem* gem)
   Добавляет гем к оружию, увеличивая урон.
- GetDamage()
   Возвращает суммарный урон с учетом гемов.
- RemoveGem(Gem* gem)
   Убирает гем из оружия.

### "Armor" (Броня)
- AddGem(Gem* gem)
   Добавляет гем к броне, увеличивая защиту.
- RemoveGem(Gem* gem)
   Убирает гем из брони.
- GetInfo()
   Возвращает информацию о броне.

### "Gem" (Гем)
- GetBonus()
   Возвращает бонус от гема (урон или защита).
- GetInfo()
   Возвращает информацию о геме(имя и бонус).
- GetType()
   Возвращает инфомацию о типе гема.

Классы "Chestplate", "Sword" наследованны публично от класса "Weapon" и имеют аналогичные методы.


## Локации
### "Locations"
- DisplayInfo() 
   Выводит информацию о локации (тип, погода, свойства).
- HasProperty(const std::string& property)
   Проверяет наличие свойства у локации (например, "Enemies nearby").
- GetWeather()
   Возвращает погоду в настоящий момент.
- GetType()
   Возвращает тип местности в данный момент.
- AddProperty(const std::string& property)
   Добавляет свойства локации в массив с свойствами для генерации.
- LocationsGenerator()
   Создает локацию вокруг игрока.   


## Логика игры
Объект LogicHandler отвечает за организацию логики игры.
### "DefaultLogic" (Базовый класс)
- DoCommand(std::string& console_command)
   Обрабатывает введенную команду, ищет соответствие в списке зарегистрированных команд.
- AddCommand(std::string command_name, std::shared_ptr<ICommand> command)
   Регистрирует новую команду для текущего игрового состояния.
- GetCommands()
   Возвращает список доступных команд (используется для отображения в помощи).

### "FightLogic"
- StartFight()
   Запускает цикл боя: поочередные атаки игрока и врагов, проверка смерти.
- CreateEnemies()
   Генерирует врагов через EnemyFactory (гоблины/скелеты).
- AddEnemy(std::shared_ptr<Enemy> enemy)
   Добавляет врага в текущий бой.
- CreateEnemies()
   Создает врага

### "LogicHandler"
- ChangeLogic(DefaultLogic *new_logic)
   Перенаправляет команду активной логике (например, из города в бой).
- GetInstance()
   Singleton-паттерн: гарантирует единственный экземпляр обработчика.

### "MainMenuLogic"
- GetInstance()
   Инициализирует команды главного меню: "new game" → NewGame, "load" → LoadGameCommand, "list" → ListSavesCommand.

### "ShopLogic"
- OnShopOpen()
   Генерирует 3 случайных товара при открытии магазина.
- GetCommoditys()
   Возвращает список доступных для покупки предметов.
- GetInstance()
   Добавляет команды в логику

### "TownLogic"
- GetInstance()
   Регистрирует команды для города:  
   "explore" → переход к исследованию,  
   "shop" → открытие магазина,  
   "inventory" → просмотр инвентаря.

## Сохранения
- "SaveGame(std::shared_ptr<Player> player)"
   Сохраняет прогресс игрока в SQLite базу
   Создает таблицу `player_progress` если она не существует
   Сохраняет:
    Основные параметры (имя, здоровье, урон, опыт, уровень)
    Экипировку (левая рука, правая рука, тело)
    Содержимое инвентаря (в формате JSON)
   Обрабатывает ошибки подключения и выполнения SQL
- "LoadGame(const std::string& playerName, const std::string& filename)"
   Загружает сохранение игрока из базы данных
   Возвращает `shared_ptr<Player>` или `nullptr` при ошибке
   Восстанавливает:
    Основные характеристики игрока
    Экипированные предметы (через `PlayerGetItem::Execute`)
    Предметы в инвентаре (парсинг из JSON)
   Обрабатывает ошибки:
    Отсутствие игрока
    Проблемы с парсингом JSON
    Ошибки подключения к БД
- "ListSaves(const std::string& filename)"
   Возвращает список всех сохраненных игроков
   Возвращает вектор строк с именами персонажей
   Обрабатывает ошибки подключения к БД
- "ParseItem(const std::string& itemStr)"
   Внутренний метод для парсинга строки в предмет
   Поддерживает типы:
    "Sword" (ищет подстроку "Damage: ")
    "Chestplate" (ищет подстроку "Defence: ")
    "Gem" (ищет подстроку "bonus: ")
   Возвращает `shared_ptr<IItem>` или `nullptr` при ошибке
   Обрабатывает исключения при парсинге чисел


## Инвентарь
### "PlayerInventory"
- AddItem(std::shared_ptr<IItem> item)
   Добавляет предмет в инвентарь игрока
- EquipWeapon(std::shared_ptr<IItem> weapon)
   Экипирует оружие, заменяя текущее при подтверждении.

- RemoveItem(std::shared_ptr<IItem> item) 
   Уничтожаает предмет из инвенторя.
- GetInfo()
  Возвращает строку с информацией о слотах экипировки и содержимом рюкзака.

## Вспомогательные системы (Utility)
Классы для обработки специфических игровых событий и взаимодействий.

### "GetItemFromShop"
- Execute(int item_index)  
   Возвращает предмет из магазина по индексу. Используется в команде "BuyCommand".

### "GiveLoot"
- Execute(std::vector<std::shared_ptr<IItem>> loot);
   Обрабатывает передачу предмета в инвентарь.

### "OnPlayerDeath"
- Execute
   Выводит сообщение "YOU ARE DEAD"

## Запуск игры
int main() {
  try {
    GameInitialisation::StartGame();

    CommandHandler* handler = CommandHandler::GetInstance();
    std::string input;
    while (true) {
      std::cout << "> ";
      std::getline(std::cin, input);
      handler->ExecuteCommand(input);
    }
  } catch (const std::exception& e) {
    std::cerr << "Error: " << e.what() << '\n';
    return 1;
  }

  return 0;
}
