Описание игры

Это текстовая RPG игра с элементами исследования, боёв и прокачки персонажа. Игрок может исследовать различные локации, сражаться с врагами, собирать добычу, посещать магазин и улучшать своего персонажа.

  
Геймплей

Основные механики игры:

- Создание нового персонажа или загрузка существующего из базы данных

- Исследование случайно генерируемых локаций

- Пошаговые бои с врагами (гоблинами, скелетами)

- Система прокачки персонажа (уровни, опыт)

- Инвентарь с оружием и броней

- Магазин для покупки снаряжения

- Система сохранения прогресса

Процесс запуска windows

1. Убедитесь, что у вас установлен компилятор C++ (g++ или аналогичный)
    
2. Скачайте все файлы проекта
    
3. Скомпилируйте проект командами:  
    mkdir build && cd build  
    cmake ..cmake --build .
    
4. Запустите игру:  
    ./derelict_land.exe
    

Запуск через bash
```bash 
$ sh build.sh
$ cd build && ./derelict_land
```

  Сборка через докер
  ```bash
  $ docker build -t rpg_game .
  $ docker run -it --rm rpg_game
```
  

Управление

Игра полностью управляется с помощью текстовых команд. Доступные команды отображаются в каждом меню (введите "help" для списка команд в текущем меню).
